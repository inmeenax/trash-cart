# Maison Hampers — Multi-page premium gifting website

Pages:
- index.html — Home
- shop.html — Shop + product details
- occasions.html — Occasion discovery
- custom.html — Custom hamper builder
- about.html — Brand story
- contact.html — Contact

Features:
- Responsive/mobile-first
- Add to cart with localStorage
- Cart drawer and quantities
- Product detail modal
- Multiple gift packaging choices with upgrade pricing
- WhatsApp cart ordering
- Sticky mobile CTA
- Smooth reveal animations
- Responsive navigation
- Premium typography and visual system
